Desktop Application / C# & WPF

Информационная система складского учета товарно-материальных ценностей

Профиль: Десктопная разработка (C# / WPF)
Технологии: C#, WPF (.NET Framework), MS SQL Server, Entity Framework
Сфера: Автоматизация бизнеса / Строительство
Посмотреть код на GitHub

Описание проблемы и задачи

В строительной компании учет материалов и инструмента на складе велся вручную или с использованием несогласованных таблиц. Это приводило к задержкам при отгрузках, неточностям в остатках и отсутствии быстрой аналитики по движению ТМЦ.

Цель проекта: Разработать надежное десктопное приложение для автоматизации складских операций, контроля остатков в реальном времени и генерации отчетов.

Реализованный функционал

  • Учет материалов и категорий: ведение номенклатуры, отслеживание минимальных остатков.
  • Документооборот: оформление приходных и расходных накладных, актов списания.
  • Ролевая система доступа: разграничение прав (Администратор — управление доступом, Кладовщик — проведение документов).
  • Поиск и фильтрация: быстрая сортировка по поставщикам, объектам строительства и датам.
  • Аналитические отчеты: автоматическое формирование ведомостей движения материалов.

Архитектура и Базы Данных

Приложение спроектировано с разделением на слои (UI, Business Logic, Data Access).

UI: WPF / XAML
Бэкенд: C# / .NET Framework
БД: MS SQL Server
